# 👥 HR Analytics Dashboard

## 📌 Overview
تحليل بيانات 50 موظف لقياس معدل الاستقالة وتوزيع الرواتب باستخدام Power BI — المشروع التاني من سلسلة 12 مشروع.

## 📊 Key Metrics
- **Total Employees:** 50
- **Active Employees:** 39
- **Resigned Employees:** 11
- **Turnover Rate:** 22%
- **Average Salary:** 8,940 EGP
- **Average Tenure:** ~3.5 Years

## 🔍 Key Insights
- قسم Marketing أعلى نسبة استقالة (40%) — مؤشر خطر
- قسم IT أعلى متوسط راتب (11.5K EGP)
- معدل الاستقالة العام (22%) يتجاوز المعدل الصحي (10-15%)

## 💡 Recommendations
1. مراجعة نظام الحوافز والمكافآت
2. تقييم بيئة العمل والإدارة في قسم Marketing
3. دراسة العلاقة بين الراتب ومعدل الاستقالة

## 🛠️ Tools & Skills
- Power BI Desktop
- DAX (Measures: COUNTROWS, FILTER, AVERAGE, DIVIDE)
- Calculated Columns (DATEDIFF, IF, TODAY)
- Data Visualization (Bar, Donut, Cards, Slicers)
- HR Analytics Concepts (Turnover Rate, Tenure)
