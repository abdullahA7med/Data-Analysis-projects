# 🛒 E-Commerce Sales Dashboard

## 📌 Overview
تحليل مبيعات متجر إلكتروني باستخدام Power BI — المشروع الأول من سلسلة 12 مشروع.

## 📊 Metrics
- **Total Revenue:** 126.9K
- **Total Orders:** 30
- **Average Order Value:** 4.23K

## 🔍 Key Insights
- القاهرة تمثل النصيب الأكبر من المبيعات
- الإلكترونيات = 94% من المبيعات
- انخفاض تدريجي في المبيعات (يناير → مارس)

## 💡 Recommendations
1. مراجعة استراتيجية التسويق للأقاليم الأخرى
2. التحقق من سبب الانخفاض الشهري
3. زيادة التركيز على فئة الإكسسوارات
